This is my Geography trivia web quiz! try it out:  https://abask0.github.io/GeoJourneyquizz/

My digital outcome is a web quiz which provides instant feedback after each question. The purpose of this quiz is to provide a fun, learning and interactive experience for users, specifically those who have a keen eye for geography questions. 
My quiz starts and opens to where it asks the users how many questions they would like to answer. Then beneath that question are four options for the different question amounts (10,15,20,25). This feature allows the user to customise their experience. Once the user makes their selection, it automatically starts on the first question. Another feature my quiz has is a randomised question order. The questions are shuffled by use of the Fisher Yates algorithm, and ensures that for every quiz the questions are shuffled.

There is the title of the quiz on top (Geojourney), the question shown in the green box (easy to tell it is a question) and beneath the answer options). Once the user selects an answer, it displays “correct” or “incorrect” then beneath displays more information about the correct answer. This is the instant feedback that is shown in my quiz so that the user can tell right after they answer the question whether they were right or not. The fun facts and snippets of information can also be useful in learning more things and in remembering the information more. The button on the utmost left corner of the screen for quiz users is the “Next Question” button. This allows the user to ponder and think more on the answer, and read the information, before making their own choice and in their own time, moving on. 

The advanced techniques which my quiz uses is the Fisher Yates algorithm, shallow copy, and customisable quiz lengths selection. Using the Fisher Yates algorithm, it allows the program to shuffle questions. This algorithm makes every possible order of questions equally likely. Linked with shuffling is making a shallow copy of the array. This technique copies the array and shuffles the copied array instead of changing the original array. This preserves the list of questions and the original remains the same. The quiz has a customisable quiz length selection as it adjusts to the number of questions the user selects, and displays that customised quiz. 
My quiz also remains functional as there are no literals in my code, meaning I can change questions or add and delete some, and the quiz will adjust to these changes. This ensures future proofing, and an adaptable program for the long-term.

This geography themed trivia quiz can be used for students learning geography, those who are interested in learning more about geography, or for anyone for fun and those who enjoy learning new things. This quiz is public and published on GitHub and so is accessible to everyone wanting to use it.
